屏東無人機競賽｜Gigo Drone 公版程式 操作與調參指南

依簡章 8.「無人機程控任務賽」規則撰寫：依序降落 A → B → C 圓環、穿越兩道立式穿環、最後停在終點區。程式檔：屏東無人機競賽_公版.hex（拖進 makecode.microbit.org 即以積木開啟）。

賽道總長 900 cm
每段中心距 200 cm
起飛預設高度 120 cm
理想滿分 95 分
每回合 3–5 分鐘

一、互動式 micro:bit 按鍵與飛行模擬器

按鍵（和實機相同）

出發／終點區 圓環目標 A／B／C 立式穿環（側視，內徑 60 cm） 無人機飛行軌跡
側視圖：橫軸是賽道長度、縱軸是高度（cm）。穿環一約在 140 cm、穿環二約在 760 cm。模擬器假設無人機每段都飛得剛好，實際落點要靠試飛調整。

二、比賽規則重點與飛行路線

項目規則（簡章 8.1、8.5）程式怎麼做
圓環降落沿路徑方向依序降落在 A、B、C 圓環，分數看落點，取最佳。A：10/8/6/4/2；B：20/16/12/8/4；C：30/24/18/12/6每一段飛完都降落，停 2 秒再起飛
立式穿環兩道高低不同的穿環，每道 10 分。穿環一在起飛區與 A 之間，穿環二在 C 與終點區之間第 1 段飛 70 cm、第 4 段飛 50 cm，對準圓心
終點區完整停在圖內 15 分第 4 段結束降落在終點區中心
臨時停放區每次無人機降落點都可視為臨時停放區；可重複解題，分數累進按 B 選起飛位置，從失敗那關接著飛
名次比序終點區 → C 圓環 → 穿環 → B 圓環 → A 圓環C 環與終點區最重要，優先調準

每一段的動作順序

起飛（倒數 3-2-1-0）→ 升到 120 cm→ 降到這段高度並確認→ 往前 200 cm（一次飛完）→ 降落→ LED 顯示到達位置
段從 → 到飛行高度途中障礙降落得分
第 1 段出發區 S → A70 cm穿環一（較高，圓心 70，可過 40～100），離起飛點約 90 cm穿環 10 分＋A 環 2～10 分
第 2 段A → B60 cm—B 環 4～20 分
第 3 段B → C60 cm—C 環 6～30 分
第 4 段C → 終點區 E50 cm穿環二（較低，圓心 50，可過 20～80）穿環 10 分＋終點區 15 分

三、按鍵與 LED 顯示對照

操作功能LED 顯示
按 B切換起飛位置（飛行中無效）S → A → B → C → S…
按 A開始任務：先檢查電壓，再從起飛位置一段一段飛到結束位置起飛倒數 3、2、1、0（飛行中一直顯示 0）；每次降落後顯示 A／B／C／E；完成顯示 ✔
按 A+B緊急降落並停止任務✘
摸 logo（V2）顯示電池電壓捲動電壓數字
電壓不足低於「最低電壓」不起飛哭臉 → 電壓 → ✘
已落地卻停在 0程式還在等無人機回覆，按鍵沒反應（見下方手動接續）0 不動
從中途重飛：把無人機放回最後成功降落的圓環中心、機頭朝終點區，按 B 切到該位置（例如「B」），再按 A，就會接著飛 B → C → 終點。

LED 停在「0」不動：手動接續

起飛倒數到 0 之後，整段飛行 LED 都顯示 0，降落完成才換成位置字母。如果無人機已經落地，LED 卻一直停在 0，代表 micro:bit 沒收到無人機「動作完成」的回覆，程式停在等待中，按 A、按 B 都不會有反應。程式沒辦法自己跳過，請照下面步驟接續：

  1. 確認無人機已經停穩、螺旋槳停止。若還在空中，先按 A+B。
  2. 記下落在哪個位置（例如 B 環）。
  3. 按 micro:bit 背面的重置鍵（或拔插電源），LED 回到 S。
  4. 摸 logo 看電壓：顯示數字代表連線正常；先出現 ✘ 再顯示 0 代表讀不到無人機，請把 micro:bit 插緊、檢查 P13／P14。電壓偏低就換電池。
  5. 無人機留在降落處（或依裁判指示擺放），機頭朝終點區。
  6. 按 B 切到剛才的位置（例如「B」）→ 按 A，接著飛下一段。
重置後程式從頭開始，起飛位置一定要重新用 B 選，否則會從出發區那段重飛。比賽中能否觸碰 micro:bit 與無人機，依簡章與裁判規定。
同一個地方一再卡住：換一顆滿電電池再試。換電池就正常是電力問題；換了還卡住是連線問題（micro:bit 沒插緊、接腳接觸不良）。

五、程式架構（函式說明）

函式做什麼
執行任務檢查電壓 → 從「起飛位置＋1」那段開始，用迴圈一段一段呼叫「飛一段」直到「結束位置」
飛一段起飛 → 升降到（這段高度）→ 往前飛（每段距離）→ 降落 → 顯示位置 → 等待
升降到設定高度後，反覆讀高度感測器，直到誤差小於「高度誤差」或次數用完。避免還在 120 cm 往下降時就往前飛撞到環
往前飛把距離乘上「距離校正」後一次往前飛完，最後做「左右修正」
段高度輸入第幾段，回傳那一段的高度
顯示位置0～4 對應 LED 顯示 S、A、B、C、E

六、上場前檢查清單與現場修正速查

上場前

  1. 多準備幾顆充飽的電池：一顆約可飛 6～7 分鐘、充電要 1.5 小時，兩次比賽之間直接換電池。
  2. 摸 logo 看電壓，要高於「最低電壓」。
  3. micro:bit 與無人機連線（P13／P14）接好；沒接好時程式會一直等回覆而停住。
  4. 看一下地墊：無人機靠拍攝地面來定位，亮面反光或燈光直射的地面容易飄，練習時間先觀察落點穩不穩。
  5. 確認場地淨高：每段都會先升到 120 cm，天花板建議 1.6 m 以上。
  6. LED 顯示 S（出發區），無人機放在出發區中心、機頭朝終點區（電源燈在正後方）。
  7. 操作的人站在無人機後方約 2 公尺；A+B 緊急降落要等目前的動作做完才會生效。

現場修正速查

看到的狀況改哪個參數
每次都降在圓心前面（不夠遠）距離校正 調大，例如 100 → 105
每次都降在圓心後面（太遠）距離校正 調小，例如 100 → 95
每次都偏左 / 偏右左右修正 填正數往右、負數往左
撞到穿環上緣 / 下緣該段高度調低 / 調高 5～10 cm
穿環時突然往上跳該段高度調低 5～10 cm，讓上方多留空間
落點忽前忽後、不固定先不要改參數，檢查地面是否反光、燈光是否直射；換電池再試
起飛後停很久才往前高度誤差 調大，或 高度確認次數 調小
前進時晃動、落點不穩穩定等待時間 調大，讓起飛後先停穩再前進
B 之後失敗放回 B 中心 → 按 B 選「B」→ 按 A 接著飛
已落地但 LED 一直顯示 0不是參數問題：重置 micro:bit → 按 B 選落點位置 → 按 A（見手動接續）
只在一次試飛看到偏差就改參數很容易越調越亂。同一個設定至少飛 2～3 次，看到固定方向的偏差再改。
