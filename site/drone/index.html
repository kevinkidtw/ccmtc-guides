屏東無人機競賽｜Gigo Drone 公版程式 操作與調參指南

依簡章 8.「無人機程控任務賽」規則撰寫：依序降落 A → B → C 圓環、穿越兩道立式穿環、最後停在終點區。程式檔：屏東無人機競賽_公版.hex（拖進 makecode.microbit.org 即以積木開啟）。

賽道總長 900 cm
每段中心距 200 cm
起飛預設高度 120 cm
理想滿分 95 分
每回合 3–5 分鐘

一、互動式 micro:bit 按鍵與飛行模擬器

micro:bit LED
按鍵（和實機相同）
目前起飛位置：S 出發區。按 A 依序飛、按 B 刷分、摸 logo 切換起飛位置。
出發／終點區 圓環目標 A／B／C 立式穿環（側視，內徑 60 cm） 無人機飛行軌跡
側視圖：橫軸是賽道長度、縱軸是高度（cm）。模擬器假設每次都飛得剛好，實際落點要靠試飛調整。

二、比賽規則重點與飛行路線

項目規則（簡章 8.1、8.5）程式怎麼做
圓環降落沿路徑方向依序降落在 A、B、C 圓環，分數看落點，取最佳。A：10/8/6/4/2；B：20/16/12/8/4；C：30/24/18/12/6按 A：每段飛完都降落
立式穿環兩道高低不同的穿環，每道 10 分。穿環一在起飛區與 A 之間，穿環二在 C 與終點區之間第 1 段飛 70 cm、第 4 段飛 50 cm
終點區完整停在圖內 15 分第 4 段降落在終點區中心
臨時停放區每次降落點都可視為臨時停放區；可重複解題，分數累進摸 logo 選起飛位置接著飛；按 B 反覆刷「穿環一＋C」
名次比序終點區 → C 圓環 → 穿環 → B 圓環 → A 圓環C 環與終點區優先調準

按 A：每一段的動作

起飛（倒數 3-2-1-0）→ 升到 120 cm→ 降到這段高度→ 往前 200 cm→ 降落，LED 顯示位置
段從 → 到飛行高度途中障礙降落得分
第 1 段出發區 S → A70 cm穿環一（圓心 70，可過 40～100），離起飛點約 90 cm穿環 10 分＋A 環 2～10 分
第 2 段A → B60 cm—B 環 4～20 分
第 3 段B → C60 cm—C 環 6～30 分
第 4 段C → 終點區 E50 cm穿環二（圓心 50，可過 20～80）穿環 10 分＋終點區 15 分

按 B：刷分（出發區 → 穿環一 → C）

起飛（倒數 3-2-1-0）→ 升到 120 cm→ 降到「第1段高度」→ 往前 600 cm（每段距離 × 3），穿過穿環一→ 降落在 C
  1. 無人機放在出發區中心、機頭朝終點區，按 B（不受起飛位置影響）。
  2. 降落後 LED 顯示 C。拿回出發區，再按 B 刷下一次。
  3. 一次飛 600 cm 誤差較大，先實測 C 的落點再調 距離校正。
跳過 A、B 直接降落在 C 的計分方式，以簡章與裁判規定為準。

三、按鍵與 LED 顯示對照

操作功能LED 顯示
按 A從起飛位置一段一段飛到結束位置倒數 3、2、1、0（飛行中停在 0）；降落後顯示 A／B／C／E；完成顯示 ✔
按 B刷分：出發區 → 穿環一 → 降落在 C倒數 3、2、1、0；降落後顯示 C
按 A+B在當下位置降落，停止任務（移動中也有效）✘
摸 logo（V2）切換起飛位置（飛行中無效）S → A → B → C → S…
長按 logo（V2）顯示電池電壓（飛行中無效）電壓數字
逾時降落移動或調高度超過「逾時降落秒數」沒完成，自動在原地降落✘
從中途接著飛：無人機放在最後降落的圓環中心、機頭朝終點區，摸 logo 切到該位置（例如「B」），按 A 就接著飛 B → C → 終點。

已落地但 LED 停在「0」：手動接續

代表 micro:bit 沒收到無人機「動作完成」的回覆，程式停在等待中，按鍵沒有反應。

  1. 無人機還在空中就先按 A+B。
  2. 按 micro:bit 背面的重置鍵，LED 回到 S。
  3. 長按 logo：顯示電壓代表連線正常；顯示 ✘ 再 0 代表連線有問題，把 micro:bit 插緊、檢查 P13／P14。
  4. 摸 logo 切到落地的位置 → 按 A 接著飛；刷分則把無人機拿回出發區按 B。
重置後起飛位置要重新選。比賽中能否觸碰 micro:bit 與無人機，依簡章與裁判規定。

四、可調整參數速查表（「當啟動時」積木裡的設定變數）

👆 點下方表格中的任一個參數，圖上會用橘色標出它影響的段落或位置。
參數名稱預設值用途什麼時候調
第1段高度70出發區 → A，穿過穿環一；刷分也用這個高度（cm）撞環上緣調低、下緣調高
第2段高度60A → B 的飛行高度（cm）一般不用改
第3段高度60B → C 的飛行高度（cm）一般不用改
第4段高度50C → 終點，穿過穿環二（cm）撞環上緣調低、下緣調高
每段距離200每段往前飛的距離（cm），刷分飛 3 倍場地中心距不是 200 才改
距離校正100距離放大百分比落點不夠遠調大（105）、太遠調小（95）
左右修正0飛完往右（正）或往左（負）移幾 cm每次偏左 10 cm → 填 10
結束位置4按 A 飛到哪裡停：4＝終點、3＝C、2＝B、1＝A練習只飛前幾段
穩定等待時間800動作之間的停頓（毫秒）會晃就調大；想快一點可試 500
逾時降落秒數20移動或調高度超過幾秒沒完成就原地降落，0＝不使用比刷分「往前飛」實測秒數多 5 秒以上
「程式狀態」區的變數由程式自己管理，不要改。起飛倒數、升到 120 cm、降落速度由擴展與無人機決定，程式改不到。

五、程式架構（函式說明）

函式做什麼
執行任務按 A：從「起飛位置＋1」那段開始，逐段呼叫「飛一段」到「結束位置」
飛一段起飛 → 升降到 → 往前飛 → 降落 → 顯示位置
刷分按 B：起飛 → 升降到（第1段高度）→ 往前飛（每段距離 × 3）→ 降落 → 顯示 C
升降到設定高度，再停「穩定等待時間」
往前飛距離乘上「距離校正」後一次飛完，再做「左右修正」
開始計時移動或調高度前記下時間
重複無限次逾時降落：動作超過「逾時降落秒數」沒完成就降落
段高度回傳第幾段的高度
顯示位置0～4 對應 LED 顯示 S、A、B、C、E

六、上場前檢查與現場修正

上場前

  1. 使用大會提供的充飽電池。
  2. micro:bit 與無人機（P13／P14）插緊。
  3. 地面反光或燈光直射容易飄，先試飛看落點穩不穩。
  4. 天花板建議 1.6 m 以上（起飛會先升到 120 cm）。
  5. LED 顯示 S，無人機放在出發區中心、機頭朝終點區。
  6. 按 B 實測一次，記下往前飛的秒數，逾時降落秒數 至少多 5 秒。

現場修正速查

看到的狀況怎麼做
降在圓心前面（不夠遠）距離校正 調大，例如 105
降在圓心後面（太遠）距離校正 調小，例如 95（刷分 1% 約 6 cm）
每次都偏左／偏右左右修正 正數往右、負數往左
撞到穿環上緣／下緣該段高度調低／調高 5～10 cm
實際高度和設定不同差多少補多少（設 70 實際 62 → 改 78），在場地旁貼刻度側拍校正
落點忽前忽後先檢查地面反光、燈光；同設定多飛幾次再調
前進時晃動穩定等待時間 調大
有風，在落點上方一直晃在圓環正上方時按 A+B；沒按會在逾時後自動降落。沒有穿環的段可飛低一點
還沒到落點就自動降落逾時降落秒數 調大
降落後按鍵沒反應、LED 停在 0見手動接續
同一個設定至少飛 2～3 次，看到固定方向的偏差再改。
